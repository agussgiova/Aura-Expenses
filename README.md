# Aura - Personal Finance & Expense Tracker

Una aplicación web moderna y elegante para el control de finanzas y gastos personales basada en el diseño de **Aura Finance**.

## ✨ Características
- 🔐 Inicio de sesión con autenticación interactiva y modo demo.
- 💰 Dashboard financiero con cálculo en tiempo real de Balance Total, Ingresos y Gastos del mes.
- ➕ Registro de nuevas transacciones con selección dinámica de categorías, fecha, monto y notas.
- 🗑️ Gestión y eliminación de transacciones con persistencia local (`localStorage`).
- 🎨 Interfaz moderna y minimalista con estética Dark Glassmorphism, Tailwind CSS e íconos de Material Symbols.
- 📱 Diseño totalmente responsivo adaptable a computadoras y dispositivos móviles.

## 🚀 Cómo ejecutar localmente

1. Clonar el repositorio o descargar los archivos.
2. Iniciar el servidor local:
   ```bash
   node server.js
   ```
3. Abrir el navegador en [http://localhost:3000](http://localhost:3000)
